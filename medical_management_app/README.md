# Medical Management Application

This project is a simple application for managing a medical practice, including patient records, appointments, prescriptions, and doctor schedules.

It consists of two main parts:
- [Backend](./backend/README.md): A Node.js and Express API.
- [Frontend](./frontend/README.md): A React user interface.

Please refer to the README files in each directory for specific setup and running instructions.

## Overview

The application aims to provide a user-friendly interface for medical staff to:
*   Manage patient information and medical history.
*   Schedule and track patient appointments.
*   Create and manage prescriptions.
*   Manage doctor information and their availability schedules.

## Technology Stack

*   **Backend**: Node.js, Express.js, MySQL (using `mysql2` driver)
*   **Frontend**: React (Create React App), Axios (for API calls), React Router (for navigation)
*   **Testing**:
    *   Backend: Jest, Supertest
    *   Frontend: Jest, React Testing Library

## Getting Started

1.  **Clone the repository (if applicable).**
2.  **Set up the Backend:** Follow the instructions in the [Backend README](./backend/README.md). This includes setting up the MySQL database and installing Node.js dependencies for the backend.
3.  **Set up the Frontend:** Follow the instructions in the [Frontend README](./frontend/README.md). This includes installing Node.js dependencies for the frontend.
4.  **Run the Backend:** Start the backend server.
5.  **Run the Frontend:** Start the frontend development server.

Refer to the individual README files for more detailed instructions on prerequisites, setup, running the applications, and running tests.
